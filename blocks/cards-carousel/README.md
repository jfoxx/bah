# cards-carousel

Custom **cards** block. Purpose: card-slider.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No authored variations. Styling adapts to context:

- Text-only cards rotate black / white / medium gray backgrounds.
- Image cards (image cell + text cell) are white in light sections.
- Image cards in a `dark` (black) section keep the black / white / medium gray rotation,
  show 1 / 2 / 4 cards per view (mobile / 640px+ / 1024px+) and use an orange active dot.
